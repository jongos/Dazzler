# Roboto distribution

Checked: 2026-09-28

License: Apache-2.0

The bundle follows the site's roboto-2 GitHub source: Apache 2.0, six upright weights plus italics. The site's OFL label and nine-weight listing refer to a different generation. Do not mix Roboto versions silently.

Font binaries are copied byte-for-byte; they have not been subsetted, renamed internally, converted, or relicensed.
