# EB Garamond distribution

Checked: 2026-09-28

License: OFL-1.1

The bundle uses Google Fonts' contemporary EB Garamond distribution, not every optical-size design in Georg Duffner's original project.

Font binaries are copied byte-for-byte; they have not been subsetted, renamed internally, converted, or relicensed.
