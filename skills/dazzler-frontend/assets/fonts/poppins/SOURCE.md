# Poppins distribution

Checked: 2026-09-28

License: OFL-1.1

The Open Foundry description mistakenly discusses Bagnard. This entry instead uses the ITF/Google distribution and inspected font data. Stable static files are bundled rather than the upstream beta variable files.

Font binaries are copied byte-for-byte; they have not been subsetted, renamed internally, converted, or relicensed.
