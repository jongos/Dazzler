# Junicode distribution

Checked: 2026-09-28

License: OFL-1.1

The bundle is current Junicode 2 variable webfonts. The site's old Fromager mirror and historical character counts are not the current distribution. Test specialist shaping and private-use characters explicitly.

Font binaries are copied byte-for-byte; they have not been subsetted, renamed internally, converted, or relicensed.
