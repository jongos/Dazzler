# League Gothic distribution

Checked: 2026-09-28

License: OFL-1.1

Four release webfonts include regular and condensed widths, each upright and italic. Condensed is a separate CSS family alias.

Font binaries are copied byte-for-byte; they have not been subsetted, renamed internally, converted, or relicensed.
