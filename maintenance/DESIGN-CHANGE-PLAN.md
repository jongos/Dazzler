# Dazzler Design Change Plan

Status: Prompt-led document and gallery policies implemented locally; native surface/font fixes verified. Full gallery regeneration remains a release prerequisite.
Created: October 6, 2026.
Revision: 9 — continuous mathematical palette exploration within the existing color framework.

## October 7: Mathematical Palette Expansion

New palette work defaults to continuous exploration rather than catalog matching. Original orchestration combines rotated Halton sampling, hue/lightness-dependent chroma-boundary bisection, authored hue relationships and chromatic page fields, existing semantic-role/contrast validation and farthest-first OKLab separation. Chosen seeds and surfaces flow through studio, persistent records and native/chart tokens. Catalog selections and existing generation contracts remain deterministic.

Evaluate uniqueness and minimum separation on actual generated outputs; inspect palette area and text/control relationships in rendered context. Never equate a 128-bit seed space or continuous coordinates with proven billions of unique, good designs. Natural-language interpretation remains the agent's responsibility.

## October 7: Maximum Character Within the Brief

Every output now aims for a committed, memorable design voice, including basic professional documents. All changes remain inside the existing design principles, deslop framework, tokens, font/color engines, composition/refinement controls, document/visualization paths, persistent records and delivery gates; no parallel styling system or compulsory dial preset. Added principles for typographic composition, content-derived visual rules, density/release, purposeful surfaces, coherent variation, meaningful interaction and precision as drama. Generic or incoherent output triggers another design/render pass. High ambition does not waive exact user constraints, data integrity or working controls.

The workflow planner includes distinction for every kind and scope. A reported distinction pass requires a structured observed review; missing reviews and declared generic/incoherent results cannot pass. This enforces evidence completeness, not taste. Research includes Pentagram's Public Theater and MIT Media Lab, Lusion and Google's expressive-design research. The latter supports expressive hierarchy but contradicts a universal claim that forced adaptation improves experience.

Next evaluation: run repeated same-brief comparisons covering basic professional, data-heavy, expressive, accessibility-constrained and brand-locked prompts. Blind the tool/version labels and ask people separately about memorability, fit, clarity, preference and task success. Report rejection and generic-output rates; do not equate novelty with quality or use these implementation tests as proof of a guaranteed wow reaction.

## October 7: Open Web Composition

Root causes: industry keywords forced reserved aesthetics; the composition reviewer restricted purposes to eight names; token export had no authored page relationship contract. Implemented policy generation 2, arbitrary bounded purpose descriptions and an optional responsive page-composition compiler. Preserve old saved behavior on resume. New guidance requires autonomous exploration of distinct structures and subject-specific interaction, with no mandatory template or user art-direction questionnaire.

Research includes the user's Semrush, Awwwards and Eleken references plus live Mona/Hubot Sans, Glyph Drawing Club and a Pudding-curated dithering explanation. Learn relationships, not trade dress. See the installed [web design space](../skills/dazzler-frontend/references/web-design-space.md). Compiler tests establish export behavior, not visual superiority; generated artifacts still need rendered and interaction review.

## October 7: Open Document Design and Release Gallery

Implemented locally: optional structural candidate exploration connected to the color engine, exact arbitrary page-color locks, no assumed white Word/PDF surface, prompt-first guidance and removal of automatic template selection. Original native Word studies test full-page color, editable text/tables and exported PDF. Commercial references expand compositional vocabulary; no source assets were copied.

Release rule: examples are capability demonstrations, never design defaults. Every shipment requires fresh generation from ambitious varied prompts using the current skill, actual render inspection, distinct peers and substantive visual change from the preceding release. See [gallery production](GALLERY-GENERATION.md). The evidence validator rejects missing provenance, unchanged renders and incomplete visual reviews. It does not mechanically judge beauty.

Outstanding release work: replace the entire legacy fixed gallery through that workflow. Existing examples are not retroactively certified as prompt-generated. The six same-content native studies are limited implementation evidence, not the completed release gallery or proof of billions of quality outputs.

## October 7: Capability Activation

The next problem was not a shortage of libraries: the local installed skill was stale, helper defaults remained easy to ship unchanged, and correctness checks did not require evidence of a coherent visual idea. See [the activation review](DAZZLER-ACTIVATION-REVIEW.md).

Implemented: art direction at the skill entrypoint; a substantial-work distinction check; explicit scaffolding notes for unconfigured modern tokens; validated chart annotations/reference lines; and four rendered same-content directions using real fonts, a data-derived graphic and responsive charts. Keep the existing benchmarks immutable. The new neutral baseline is a constructed specimen, not an earlier agent output.

Evaluation standard: a same-brief, repeated, blinded comparison of generated artifacts, judged for audience fit, composition, typography, chart clarity and distinctiveness. Correctness and functional failures disqualify an output. No tool-count, pixel-difference or test-count proxy establishes aesthetic superiority.

Next propagation: migrate selected gallery charts and broader document families only when their real reader task benefits; validate native outputs independently. Native editable Office annotation support and general superiority over other tools remain unproven. Preserve user brands and avoid imposing a universal Dazzler house style.

## Objective

Improve Dazzler's document and web output through distinct page architectures, stronger typography, purposeful visual hierarchy, and resilient editable files. Improve the agent workflows that select, implement and verify those capabilities. Keep the Legal, Professional, and Business DOCX templates as the first visual redesign pilots.

## Baseline and Scope

The review examined v0.26.0 template screenshots, source, helpers, tests and design guidance in the verified Git checkout. The implementation advances source metadata to v0.27.0. This file is also retained in the checkout as `maintenance/DESIGN-CHANGE-PLAN.md`.

The reviewed Word samples repeatedly use large titles, three-number strips, tinted callouts, and tables. These devices can be useful, but their prominence should depend on the reader's task. In the legal memo, counts of chronology events and review questions compete with the substantive issue. The executive report repeats a prominent title and metric strip on its continuation page. Its chart uses generic axis labels.

This plan covers the entire capability surface: guidance, routing, design records, component workflows, fonts, colors, composition, engineering, accessibility, charts, illustrations, native documents, templates, exports, packaging and evidence. Local implementation is authorized. Commit, publication and deployment have not occurred.

## Implementation Batches and Acceptance

### Batch A — Implemented and Validated Locally

1. Add original `workflow.mjs`: infer a bounded plan from kind/framework/scope/intent/features; all checks begin unrun. Optional integration through route.mjs preserves existing callers.
2. Add evidence assessment: recompute expected checks, reject unknown/duplicate claims, require evidence references for reported pass/fail, retain missing coverage, identify target/revision and state that claims are not independently verified.

Acceptance: meaningful Node regressions, existing Python/Node suites, source formatting, runtime integrity, local reference checks and host-package validation. Report actual outcomes below. This batch makes agent behavior more specific; it does not claim that new template visuals were generated.

### Batch B — Three Document Pilots Implemented

The previous guidance-only batch failed the artifact benchmark: all templates were unchanged. Investigation found the shared generator was forcing title/metric/callout treatments across different tasks, and testing only correctness rather than task-specific architecture. Removed the instruction-level quota for visual treatments and added structure-before-styling and rendered-evidence checks.

Legal now uses matter metadata, issue-led reading order and quiet evidence tables; Professional prioritizes the decision over compact measures; Business uses an offer, terms and a delivery sequence. Both Word and HTML consume the same architecture transformation. Native continuation titles are quieter. Charts have meaningful axes, and overflowing mobile tables have visible hints and tested keyboard access.

All source content values and baseline Word tokens are retained. Both versions of the three pilots were rendered in the same Word environment and their six final pages inspected. Each standard sample remains two pages. The 20 browser templates pass desktop/mobile, font, axe and interaction checks. The remaining seven document and ten UI compositions were not redesigned.

Combined editing stress exposed brittle forced pagination in Business. Flowing its logical sections and keeping paragraphs intact reduced a four-page stressed result to three; the final page remains sparse. Legal and Professional retained two pages. Substantial edits still require repagination; the stress run is not a blanket pass.

The paired-page viewer and detailed local benchmark preserve the frozen v0.26.0 baseline. Grayscale comparison supports review of structure independently of palette. No blinded user study or repeated agent-generation benchmark has been claimed.

Rebuild Legal, Professional and Business from their existing fictional facts. Legal leads with the issue and qualified analysis; the executive brief leads with the decision and supporting evidence; the proposal leads with the problem, offer and scope. Remove decorative counting where it adds no comprehension, preserving useful facts in the appropriate text or table.

Acceptance: review all native Word pages, verify source styles and reading order, test expanded content and rows in disposable copies, compare an available secondary renderer, repair supported failures, then regenerate exact-source gallery captures. Record unavailable renderers. Expand the remaining collection only after these pilots meet the same criteria; this is a quality checkpoint, not an added user-approval requirement.
