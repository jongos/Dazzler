# Phase 5 validation

Version 0.20.0 adds optional design handoff guidance and evidence-qualified product documentation. It adds no runtime integration dependency and does not change token generation or existing default design behavior.

## Scope and gates

- Figma: guidance for authorized read tools, source/mode/alias evidence, existing components, conflict handling and local token proposals. No Figma connector or authenticated fixture is available in the maintenance session. Live compatibility and write-back are not claimed.
- Mockup-first: only when requested, using available tools. A bitmap is a proposal; implementation and rendered interaction checks still follow. The comparison helper accepts navigable pages, so the reference explains a local raster wrapper and accurately describes side-by-side captures rather than a numerical fidelity score.
- Native platforms: no SwiftUI, Compose or Flutter export is added because compilation/device verification is unavailable. This follows the approved gate rather than promoting snapshot-only compatibility.
- Grok Bot: no authenticated discovery/invocation session is available. The dedicated edition remains unpromoted; community helper observations are not relabeled as a verified installation.
- Comparison: publisher documentation was refreshed on September 28, 2026. External capabilities are documented, not executed here; no adoption counts, unsupported absence claims or performance/quality rankings are included. Local network boundaries and inconclusive triggering evidence are explicit.

## Observable checks

The local handoff check imports synthetic CSS with conflicting light/dark values. Both values remain evidence, conflicts remain unresolved and no brand locks are created. It wraps a deterministic raster capture in HTML, runs the actual comparison helper, checks its captures/report, and confirms source preservation. Keyboard focus and required-field validity are checked without submitting data. This verifies local mechanics, not live Figma parsing or image-generation fidelity.

The public handoff guide is inspected at 1440, 390 and 320 pixels, with loaded local fonts/images and keyboard disclosures; the two-page print PDF is rendered and visually reviewed. Existing gallery examples are explicitly identified as fictional template demos rather than Figma imports. Website starters retain their nineteen-entry catalog with optional handoff/comp variants.

The release runs the 69 Node and 45 Python tests, extracted-platform helpers, 8 KB entrypoint / 12 KB reference budgets, font/license integrity and local links. The matching Windows x64 kit is restored and rebuilt with network APIs blocked. Publication waits for the Windows/Linux Node 20/22 matrix, browser suite and identical archive hashes; those live release outcomes are reported after execution.
