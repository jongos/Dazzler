# Style Science Integration — 0.30.0

## Scope

Imported the published 0.3.0 consumer capabilities from commit `1b28e8e6cb4572e4aafc7814b65de0f576cc5907`: core verification, capability negotiation, provider-qualified advisory decisions and bounded outcome comparisons. Original module bytes, license and hashes remain in the vendored directory. Dazzler supplies a small offline wrapper and workflow guidance.

The recipe source remains pinned separately to `b29504abf762a43ce4e2819372eb0342243e4c54`. The 1,000-recipe payload is unchanged. Uncommitted upstream color-context/revision studies and other research-only APIs were not imported. Dazzler's brand constraints, typography, composition and native delivery gates remain authoritative.

## Use

Agents discover the helper through the skill entrypoint, existing workflow routing and `references/gdc.md`. `node scripts/style-science.mjs` checks bundled capabilities. `--input review.json` assesses supplied observations or compares measured candidates; it never calls a provider or generates a design. The optional wrapper requires Node 22+. Unsupported runtimes and unavailable checks retain normal Dazzler/native review.

Model identity is a reported evidence attribute, not authentication. Moving aliases remain exploratory. Model agreement does not establish beauty; bounded engineering comparisons do not establish statistical confidence or causal improvement. The wrapper cannot authorize automatic changes or publication.

## Verification

Focused fixtures cover tampered payloads, supported/unsupported/unknown checks, missing context, stale bindings, aliases, mixed providers, ties, disagreement, stale measurements, failed feasibility, and JavaScript/Python Unicode identity parity. Final integration tests passed: 105 Node tests and 91 Python cases (one optional skip). Hash verification under optimized Python, local links, formatting and the 1,709-file runtime inventory passed. The final compact skill archives are at most 12,911,924 bytes compressed and 22,372,045 bytes unpacked, below the 24 MB gate. Archive extraction and release evidence are checked separately during shipment.

The 8 KB skill-entrypoint limit initially failed; routing text was shortened to 7,922 bytes without expanding that limit. No external inference or private data was used. The Windows sandbox can deny filesystem canonicalization; the consumer conservatively returns invalid/fallback in that case, and normal-host execution was verified separately.

The 0.30 release gallery has thirty newly authored and reviewed examples, with comparison snapshots from 0.29. Its manifest records exact artifact and runtime hashes. The offline kit and local installation must match the published release; no upstream working files or live inference are included.
