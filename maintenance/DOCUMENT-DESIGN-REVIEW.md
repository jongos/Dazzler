# Prompt-Led Documents and Release Demonstrations

October 7, 2026. Local development, not published.

## What Changed

- Page surface is a deliberate prompt-driven decision. White, tinted, saturated and dark fields are valid; an explicit arbitrary six-digit background is retained while the color engine derives readable companions.
- The real native exporter previously always selected the light palette and never painted the Word page. It now accepts paletteMode from content/design system and carries its background behind editable text into Word/PDF. The compatibility light fallback is documented as scaffolding, not a design choice.
- Inherited Word theme-font attributes were overriding selected families. Conflicting bindings are removed. PDF inspection also exposed a substituted display family in the studies; it was replaced with verified Arial Narrow/Trebuchet MS.
- The skill no longer automatically selects a template. Examples demonstrate capabilities; export an example when explicitly selected.
- Every shipment now requires freshly generated examples from ambitious sample prompts using the current skill, current-runtime provenance, actual rendered artifacts, peer distinction and substantive difference from the previous release. Preset recolors and unchanged renders fail. Release-tag CI invokes the evidence gate.

## Verified Evidence

Six original same-content studies each contain two Word-rendered pages, with native text and native source tables. Both pages retain their selected background; sampled corner pixels match the recorded colors. PDF font resources were inspected. All six source values and titles survive export. Original charts are static images, not editable chart objects.

Two editing-stress copies expand the title and prose and add three explicitly missing-data rows. Titles were deliberately recomposed at 36pt; both copies retain two readable pages. This is a repair/reflow test, not a promise that arbitrary edits preserve pagination.

The actual project.py exporter was separately tested with two-page yellow and dark-blue files. Both pages preserve the chosen surface and selected Georgia headings. These sparse functional fixtures are not gallery designs.

JavaScript: 89 tests passed. Python: 69 passed, one optional test skipped. Formatting, local links and release metadata checks passed. All ten final development packages passed structural, integrity and extracted-helper validation. The local full-library skill was refreshed: 735 files matched source and 724 runtime files passed health verification; its entire prior installation was preserved. These package checks do not satisfy the separate fresh-gallery release gate.

## Limits and Release Work

The candidate helper proposes categorical alternatives; it does not interpret a natural-language brief, author a finished document, rank beauty or establish billions of good designs. The agent must select and implement the content fit. The maintenance proof builder intentionally implements a limited set of page arrangements; several studies still share silhouettes. They therefore do not satisfy the new release gallery standard.

The entire legacy gallery still requires fresh prompt-driven generation and review before shipment. No gallery manifest has been fabricated to certify those files. Hashes establish evidence freshness, not visual quality; documented visual inspection remains required.

## Reference Notes

The design-space guide records observations from Adobe Stock, Envato and DesignCrowd: page-field coverage, asymmetric grids, varied page roles, stronger type scale, imagery and evidence integration. Their previews do not prove underlying Word editability. No paid template, photograph, logo or illustration was imported. All study content is synthetic and all diagrams are original.
