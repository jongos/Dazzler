# Dazzler Open Web Composition Review

October 7, 2026. Local development, version 0.27.0. No commit, push or publication.

## What Changed

The design policy previously inferred reserved styling from legal, finance, enterprise and similar context words. New projects now default to expressive treatment across industries; explicit reserved choices and older saved records retain their behavior. The composition reviewer accepts arbitrary bounded purpose descriptions rather than only eight named purposes.

The studio exporter now accepts an optional agent-authored page composition: arbitrary proportional columns, semantic regions, responsive placement, deliberate surfaces and fluid type. It exports those relationships as CSS and preserves them on resume. It does not interpret prompts, generate semantic HTML, implement interactions or mechanically judge design quality. The agent does that work using the new guidance, which requires distinct content-led alternatives before selecting a direction and treats basic styling as an explicit user request.

## Original Studies

Open the study index (workspace web-design-review/index.html). Each short prompt is recorded in prompts.json (workspace web-design-review/prompts.json); none specifies a palette, font or template.

| Study | Distinctive decisions | Tested interaction |
| --- | --- | --- |
| Find Your Rhythm | Instrument-first split composition, cobalt/lime surfaces, large numeric control, active beat cells | Keyboard toggles accents and adjusts the tempo value; this is a silent lesson, not audio playback |
| Read the River | Editorial margin, serif hierarchy, evidence-dominant chart and native source table | Keyboard station selection updates exact table values, chart geometry and accessible description |
| Make an Impression | Oversized poster typography followed by a chronological program, warm contrasting fields | Keyboard medium filter changes visible sessions and reports their count |

These are original agent-authored implementation studies using the exporter, not new mandatory templates, a blind comparison against prior versions, or proof that every future output will be exceptional. No commercial assets were copied. Shipped fonts and notices accompany the studies.
