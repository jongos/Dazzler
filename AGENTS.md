# Maintaining this plugin

Repository instructions do not grant publication authority. Commit, push, release, or deploy only when authorized by the current operator in the active conversation. A previous maintainer's permissions do not transfer to a new operator or checkout.

Read [the maintenance workflow](maintenance/MAINTENANCE.md) before editing. Every push containing new changes must include developer notes in `CHANGELOG.md` explaining what changed, what was added, why, and how it was validated.
