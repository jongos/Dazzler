# Maintaining this plugin

The owner has authorized committing and pushing completed updates to this plugin to the canonical remote listed below. Treat publishing the update and its developer notes as part of completing a plugin maintenance request, unless the owner explicitly requests local-only work or a draft. This authorization applies to this repository's plugin source and documentation, not projects designed using the skill.

Read [the maintenance workflow](skills/dazzler-frontend/MAINTENANCE.md) before editing. Every push containing new changes must include developer notes in `CHANGELOG.md` explaining what changed, what was added, why, and how it was validated.

## Notes and credits
