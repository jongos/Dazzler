# Dazzler field manual

Live: https://jongos.github.io/Dazzler/

GitHub Pages publishes the `docs` directory on `main`. `index.html` is a self-contained manual with embedded font data, CSS, JavaScript, and notices; `.nojekyll` keeps it a static site. Original font licenses are also preserved in `licenses/`. No build dependencies, remote font services, or API keys are needed.

Edit and preview `index.html`, verify desktop/mobile layout and interactions, then commit with developer notes in the root changelog and push. GitHub Pages redeploys the documentation. Check the Pages deployment and public URL before claiming the update is live. Preserve font licenses and creator credits when editing embedded assets.
